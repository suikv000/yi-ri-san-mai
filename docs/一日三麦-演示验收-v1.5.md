# 一日三麦演示验收 v1.5

日期：2026-10-18。范围为本地演示与只读核价；非手机真机、定时任务或交易链路验收。

## 数据证据

- 查询天津时代奥城周边5店，对最近3店读取菜单、套餐选配并核价；形成95条门店购买单元报价。
- 校验具体1+1食物选项，不把13.9元起价当成双吉价。宾水西道店本次双吉不可选，数据中不生成该店双吉套餐报价。
- 蛋白质和能量使用精确餐品的官方营养快照；缺匹配营养的新品套餐未混用相似食物数值。
- 所有调用为只读，没有领取、购卡、订单或支付。凭证未写入演示或打包文件；只读进程已退出。

## 核心验证

`node demo/verify.cjs` 通过：

- 72组预算、目标、预算口径和卡状态场景，超预算无解不输出餐单。
- 160次随机换餐检查，只改一个餐次，其他20餐与锁定保持不变，避免近期重复。
- 单点与套餐精确食物数量覆盖；重复汉堡计两份；未返回单点可乐价格时不将其当作免费产品。
- 双吉＋小玉米14.9元、482千卡、29g蛋白质以及性价比公式。
- 早餐条件价不代替普通核价，卡券兼容未知不虚减优惠，新卡全额与周分摊仍计入预算。
- 同店价格进入计划、无报价组合不可用、5分钟距离换算范围仅选择宾水西道店、锁定与预算精确边界。
- 食物营养合计、身体资料范围、目标切换、单文件脚本语法。

## 浏览器验证

- 白色背景、黑色“一日三麦”、无图形Logo。
- 三个同心圆的圆心一致、半径不同；位于日期栏之后和餐品卡片之前。切换日期更新数值。
- 移动端显示超参考文字；热量、蛋白质、脂肪圈达到100%后不隐去实际超出值。碳水、钠及当天餐费列于环下方。
- 条件暂存、放弃、应用、无效档案、无解预算、随机/手动换餐、撤销、锁定、重排、主动保存刷新精确恢复通过。
- 门店筛选、蛋白质/元排序、缺报价套餐排除、距离范围影响餐单通过。
- 320、390、768、1440像素视口无页面横向溢出，换餐弹窗位于视口内。宽比较表在自己的容器内横向滚动。
- 单文件通过本地HTTP载入，验证名称、无外部脚本、同心环、随机、撤销、条件应用和响应式；测试期间0浏览器错误、0控制台警告。
- 自动化环境不允许file://导航，因此没有将HTTP结果等同于本地文件协议验证。
