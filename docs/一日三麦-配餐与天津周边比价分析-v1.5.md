# 一日三麦：配餐与天津周边比价分析 v1.5

2026-10-18。本次先纠正购买成本，再评价营养，最后结合用户指定的示例地点天津时代奥城做逐店选择。

## 结论

旧版只把人工自选三件、四件餐放进试排，漏掉实际 1+1，并用了演示组合价。这不足以回答“预算第一、蛋白质性价比好”的需求。

现在单点、1+1、官方组合、套餐和套餐加购一起比较。先确定想吃的食物及数量，再在该店已核价的购买单元中找低价购买路径；随后把营养、价格与距离一起放进整周规划。既不强制凑三件，也不认为所有套餐都比单点便宜。

这张表说明：

- 双吉单点在这个快照中被 1+1 的购买方式明显压价。不能先按单点价算，再随手加配餐。
- 同为14.9元，玉米版本多53千卡、2g蛋白质；无糖可乐版本能量更低。应根据当天能量与蛋白缺口选择，而不是固定一种。
- 牛奶并非因为有蛋白质就一定划算。单买11元增加7g蛋白；早餐组合从单堡18元升级到牛奶组合22.5元，只多4.5元得到7g蛋白质。加购价值必须看增量价格，而非单品标价。
- 豆浆组合比单堡多3元、多6g蛋白质，同时多151千卡。它的增量蛋白质性价比高，但是否合适仍取决于全天能量。
- 单点鸡块、双份汉堡或两个1+1均可参与组合，但不以无上限堆蛋白为目标；蛋白达参考量后，不继续奖励过量摄入。

以上是特定门店、特定查询时段的比较，不是全国价格榜，也不代表适合每个人。

## 2. 地点必须进入计算，不能靠“价格组”猜价

| --- | ---: | ---: | ---: | ---: |

同一家店可能单点偏贵、某套餐相同，另一套餐又不同。因此不能用一个统一系数推算整店价格。内部价格组编号未返回，产品直接使用门店具体报价。

特别容易算错的是最近的宾水西道店：菜单上的随心配显示13.9元，但该次蓝区只返回鸡块和小薯等选项，没有双吉。这不能当成“这家双吉1+1只要13.9”。也不能据此认定它永久缺货，需在用餐时重新查。

当前分钟数仅用接口距离除以80米/分钟估算，不能作为真实步行路线，更不能冒充通勤绕路。正式 Skill 应在用户授权的位置范围内查询家、公司及通勤沿线门店，并由地图工具核算额外路程和取餐时间。当前只设置时代奥城一个示例中心。

## 3. 排餐怎样使用这些信息

1. 以预算口径为硬上限，先预留余下餐次的最低可行费用，不为了填满热量而超预算。
2. 每个候选明确食物数量；同店用单点或套餐购买单元做精确覆盖。无法核价的店与组合不可用，不按0元，也不沿用别店报价。
3. 每餐营养按实际食物相加，比较全天热量和蛋白缺口，再权衡钠、脂肪、价格、口味重复、距离与每餐分配。
4. 每元蛋白质、每100千卡蛋白质用于解释性价比。它们不能代替全天饮食质量，不能只最大化一个指标。
5. 同餐换一套保持其他20餐与门店不变，按当前店的价格检查整周上限；整周重排才重新选择门店。
6. 卡费单独记账。未核验个人优惠兼容性之前不对1+1追加虚拟折扣。

同一食物集合的购买路径在已录入购买单元内求最低成本；整周营养与重复度采用有限候选启发式，不宣称全局最优。当前3店总计95条购买单元报价、56个本地可购买候选。

## 4. 目前算出来的示例

175cm、75kg、30岁、男性公式、轻度活动、减脂、450元周现金预算、不假定持卡优惠、距离换算参考上限20分钟：

- 周餐费449.4元；平均每天约1836千卡、101g蛋白质。
- 当前能量参考1990千卡，展示区间1791—2189；蛋白质参考90g/天。
- 七天蛋白质均达到该示例参考值，但钠约3088—3803mg/天，脂肪约78—92g/天，仍偏高；不能把这份草案称为长期三餐均衡饮食。
- 同心环只表示达到参考值的比例：热量外环、蛋白质中环、脂肪内环。超过参考明确显示实际数值，脂肪满环不是奖励。

这些身体参数是演示默认值，不是用户实际身体资料；数值不是医学处方。

## 5. 卡券及未纳入项

早餐菜单中的12.6元带购卡条件，不能直接作为所有人的购买价。上海样本未带卡核价的板烧炒双蛋堡＋豆浆为21元；天津三店又分别为21.5、22、21元。

因此新候选不沿用旧版“早餐减2元、正餐减2.5元、午餐券减3元”的虚构收益。用户输入的卡价和期限仍可用于周分摊与新卡现金预算，但持卡成交价、次数规则和优惠互斥未验证前不推荐开卡。

已查询过大堡口福的选项与报价，但当前主食缺少精确对应的营养数据，未用相似汉堡替代。个人券、积分、限时活动、其他未采样门店与实际导航仍需补齐。未取得完整营养不代表不值得买，只表示现在不能有依据地参与营养排名。
